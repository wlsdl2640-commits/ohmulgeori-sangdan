# 오물거리 상단

몬스터 부속품을 다루는 상단을 키우는 방치형 도트 경영 게임입니다.

파로스 제국의 제도 하르겐. 범죄자가 우글거리는 7번가 오물거리 입구에 작은 상단을 열고, 모험가를 고용해 필드와 던전에서 부속품을 모아 오고, 그것을 팔아 상단을 키웁니다. 매달 말에는 암살자 길드가 자릿세를 받으러 옵니다.

## 플레이하기

- **웹 (아이폰·안드로이드·PC):** GitHub Pages 주소에서 바로 플레이할 수 있습니다.
  - 아이폰: Safari로 열고 공유 → 홈 화면에 추가
  - 안드로이드: Chrome으로 열고 메뉴(⋮) → 앱 설치
  - PC: Chrome이나 Edge 주소창 오른쪽의 설치 버튼
- **안드로이드 설치 파일(APK):** [최신 릴리스](../../releases/latest)에서 `ohmulgeori-sangdan.apk`를 받아 설치합니다.

진행 상황은 기기에 저장됩니다. 앱을 닫아도 최대 2시간(마탑 연구로 늘릴 수 있음)까지는 원정과 상점 판매가 계속되고, 게임 속 날짜와 시간대는 게임을 켜 둔 동안에만 흐릅니다.

## v0.6에서 바뀐 것

- **상단 본부 화면**: 첫 화면이 비스듬한 입체로 본 상단 건물이 됐다. 한 번에 한 층씩 보고, 아래쪽 층 버튼을 누르거나 화면을 위아래로 밀어 층을 옮긴다.
  - 1층은 본부이자 상점. 진열대(상점을 넓히거나 랭크가 오르면 늘어난다)에 올린 물건을 손님이 들어와 고르고, 계산대에서 값을 치르고 나간다.
  - 시설을 지으면 위로는 연금술 공방 · 훈련소 · 신전 · 여관 · 마탑(맨 위), 아래로는 대장간(지하 1층) · 은행 금고가 한 층씩 생긴다.
  - 여관에는 모험가마다 침대 · 옷장 · 보관 상자가 있는 방이 있다. 원정에서 돌아온 모험가는 자기 방에서 잠을 자고, 낮에는 훈련소에서 훈련한다. 다친 모험가는 신전 침대에 눕는다.
  - 낮과 밤에 따라 하늘과 창문, 등불이 바뀐다. 가구나 사람을 누르면 그 창이 열린다.
- **메뉴 → 하위 메뉴 → 창 → 뒤로**: 오른쪽 위 메뉴(상단 · 시설 · 모험가 · 원정 · 창고 · 의뢰)로 창을 열고, 시설 → 대장간, 모험가 → 한 사람처럼 안으로 들어간다. 뒤로 버튼이나 휴대폰의 뒤로 가기로 한 단계씩 돌아온다.
- **원정 화면**: 왼쪽 위 작은 창에 나오고, 누르면 크게 볼 수 있다.

## v0.5에서 바뀐 것

- **더 어려운 균형**: 몬스터가 더 단단하고 아프다. 필드마다 10 스테이지마다 필드 보스(1-10 … 1-50)가 길을 막고, 던전은 더 깊고 강해졌다.
- **모험가는 죽지 않는다**: HP가 다하면 쓰러지고 동료가 들것에 싣고 돌아온다. 들것은 짐 자리를 차지하고 걸음이 느려진다. 「위험하면 복귀」를 켠 파티는 누가 쓰러지면 싸움에서 빠져나온다. 전멸해도 길드 구조대가 데려오지만 가져오던 짐·장비·물약은 잃고 모두 크게 다친다.
- **신전 치료**: 부상은 경상·중상·위중. 시간이 지나면 낫고 신전에서는 훨씬 빨리 낫는다. 환자마다 하루 한 번 약초·약재·물약으로 처치하고, 성직자·성기사·역병의사를 치유사로 두면 더 빨라진다. 역병의사가 있으면 수술도 한다. 신전은 3단계까지 넓힐 수 있다.
- **거점**: 필드 보스를 쓰러뜨린 구간 다음(1-11, 1-21 …)부터 원정을 시작할 수 있다. 1-50의 주인을 쓰러뜨려야 던전 입구가 열리고, 던전을 공략하면 큰 보상과 함께 상단 랭크업 조건 하나가 채워진다.
- **상단 랭크 F → S**: 던전 공략·명성·끝낸 의뢰·누적 판매액·모험가 수·라이선스 조건을 채우고 심사를 받는다. 오를 때마다 새 필드, 새 시설(대장간 E · 은행 D · 마탑 C), 더 많은 파티·매대·여관 방, 길드 매입가·상점 손님·의뢰 보상 혜택이 열린다.
- **모험가 라이선스**: 동장 → 은장 → 금장 → 백은 → 용사. 원정에서 개인 명성을 쌓고 레벨을 채우면 모험가 길드 심사를 받아 올라가고, 오를수록 능력이 강해진다.
- **전직**: 특수직업은 상단 명성으로 해금되고(검투사 60 · 정령술사 100 · 광전사 150 · 역병의사 200 · 용기병 260 · 성기사 330 · 네크로맨서 420), 비슷한 계열 모험가를 훈련소에서 전직시킨다. 새 특수직업 역병의사.
- **숙면 피로**: 원정 동안 쌓이고 여관 방에서 자야만 풀린다(밤에 더 잘 잔다). 30 이상이면 원정에 나갈 수 없다. 원정 중 피로(야영)와는 따로 센다.
- v0.4 저장은 자동으로 옮겨진다. 지금까지 공략한 던전 수만큼 상단 랭크가 정해지고, 묘지에 있던 모험가는 크게 다친 채로 돌아온다.

## v0.4에서 바뀐 것

- **배속**: 파티 목록 오른쪽의 1× · 2× · 3× · 5× 버튼. 시뮬레이션과 그림이 함께 빨라진다(자리를 비운 동안의 보상은 실제 시간 기준).
- **24시간 시계**: 상태줄에 `3월 5일 11:40 점심`처럼 표시. 새벽(04~10시) · 점심(10~16시) · 저녁(16~22시) · 밤(22~04시). 날짜는 새벽 4시에 넘어간다.
- **APK 덮어쓰기 업데이트**: 0.4.3부터 모든 APK를 저장소의 같은 열쇠로 서명한다. 새 APK를 받아 설치하면 덮어쓰기로 업데이트되고 저장은 그대로 남는다. 앱을 열면 새 버전이 있는지 확인해 알려 준다.
- **저장 코드**: 상단 탭 → 설정에서 저장 코드를 복사하고, 다른 기기나 새로 설치한 앱(첫 화면의 「저장 코드로 이어하기」)에서 불러올 수 있다.

## 그 밖에 들어 있는 것

- **하루의 흐름**: 하늘색과 해·달·별이 바뀌고, 어두워질수록 몬스터가 더 몰려온다. 게임 속 날짜와 시간은 게임을 켜 둔 동안에만 흐른다.
- **진짜 원정**: 필드는 1-1부터 1-50까지. 피로가 쌓이면 모닥불을 피우고 잠을 자야 하고, 밤에는 야영지가 습격당하기도 한다. 마차(손수레~드워프 강철 마차)를 사면 파티가 드는 짐이 늘어난다.
- **신전의 축복**: 매달 다섯 신 가운데 하나의 축복을 내려 준다.
- **그래픽**: 외곽선과 명암이 들어간 도트, 걷기·공격·앉기·잠자기 동작, 장비 단계에 따라 바뀌는 무기·갑옷 색, 여러 겹의 풍경과 밤의 불빛.
- 그 밖에: 능력치(힘·체력·민첩·지능), 스킬 56개, 장비 4칸 × 6단계 × 품질 3단계, 대장간·은행·마탑·후원, 필드 6곳, 암살자 길드 토벌. 예전 저장은 모두 자동으로 옮겨진다.

## 개발

| 경로 | 내용 |
| --- | --- |
| `src/` | 게임 코드: 데이터(`data*.js`), 도트 그래픽(`sprites.js`·`plans.js`·`art.js`·`bg.js`·`people.js`), 시뮬레이션(`core.js`·`econ.js`), 본부 화면(`iso.js`), 화면(`ui.js`·`view.js`·`panels.js`) |
| `build.py` | `dist/play.html`(한 파일)과 `dist/web/`(설치형 웹앱)을 만듭니다 |
| `tools/android_res.py` | 안드로이드 아이콘과 시작 화면을 `android-res/`에 만듭니다 |
| `.github/workflows/` | `main`에 올리면 웹 배포와 APK 빌드가 자동으로 돌아갑니다 |

```
pip install fonttools brotli pillow
python3 build.py
```
