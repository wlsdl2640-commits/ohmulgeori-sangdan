# 오물거리 상단

몬스터 부속품을 다루는 상단을 키우는 방치형 도트 경영 게임입니다.

파로스 제국의 제도 하르겐. 범죄자가 우글거리는 7번가 오물거리 입구에 작은 상단을 열고, 모험가를 고용해 필드와 던전에서 부속품을 모아 오고, 그것을 팔아 상단을 키웁니다. 매달 말에는 암살자 길드가 자릿세를 받으러 옵니다.

## 플레이하기

- **웹 (아이폰·안드로이드·PC):** GitHub Pages 주소에서 바로 플레이할 수 있습니다.
  - 아이폰: Safari로 열고 공유 → 홈 화면에 추가
  - 안드로이드: Chrome으로 열고 메뉴(⋮) → 앱 설치
  - PC: Chrome이나 Edge 주소창 오른쪽의 설치 버튼
- **안드로이드 설치 파일(APK):** [최신 릴리스](../../releases/latest)에서 `ohmulgeori-sangdan.apk`를 받아 설치합니다.

진행 상황은 기기에 저장됩니다. 앱을 닫아도 최대 2시간(마탑 연구로 늘릴 수 있음)까지는 원정과 상점 판매가 계속되고, 게임 속 날짜와 시간대는 게임을 켜 둔 동안에만 흐릅니다.

## v0.4에서 바뀐 것

- **배속**: 파티 목록 오른쪽의 1× · 2× · 3× · 5× 버튼. 시뮬레이션과 그림이 함께 빨라진다(자리를 비운 동안의 보상은 실제 시간 기준).
- **24시간 시계**: 상태줄에 `3월 5일 11:40 점심`처럼 표시. 새벽(04~10시) · 점심(10~16시) · 저녁(16~22시) · 밤(22~04시). 날짜는 새벽 4시에 넘어간다.
- **APK 덮어쓰기 업데이트**: 0.4.3부터 모든 APK를 저장소의 같은 열쇠로 서명하고, 빌드할 때 서명을 검사한다. 새 APK를 받아 설치하면 덮어쓰기로 업데이트되고 저장은 그대로 남는다. 앱을 열면 새 버전이 있는지 확인해 알려 준다.
- **저장 코드**: 상단 탭 → 설정에서 저장 코드를 복사하고, 다른 기기나 새로 설치한 앱(첫 화면의 「저장 코드로 이어하기」)에서 불러올 수 있다.

## v0.3까지 들어 있는 것

- **하루의 흐름**: 새벽녘·점심·해질녘·밤. 하늘색과 해·달·별이 바뀌고, 어두워질수록 몬스터가 더 몰려온다. 게임 속 날짜와 시간은 게임을 켜 둔 동안에만 흐른다.
- **진짜 원정**: 필드는 1-1부터 1-50까지. 모험가에게 피로가 쌓이면 모닥불을 피우고 잠을 자야 하고, 밤에는 야영지가 습격당하기도 한다. 마차(손수레~드워프 강철 마차)를 사면 파티가 드는 짐이 늘어난다.
- **던전**: 필드마다 입구가 무작위 스테이지에 숨어 있고, 도착하면 들어갈지 지나갈지 고른다(파티마다 묻기·바로 들어가기·지나가기). 던전은 한 번만 공략할 수 있고, 공략하면 큰 보상과 명성, 그리고 특수직업 모험가가 여관을 찾아온다.
- **특수직업 6종**: 검투사·정령술사·광전사·용기병·성기사·네크로맨서. 고유 스킬은 스킬북 없이 훈련소에서 배운다.
- **신전**: 쓰러진 모험가를 300G에 되살리고, 매달 다섯 신 가운데 하나의 축복을 내려 준다.
- **그래픽**: 외곽선과 명암이 들어간 새 도트, 걷기·공격·앉기·잠자기 동작, 장비 단계에 따라 바뀌는 무기·갑옷 색, 여러 겹의 풍경과 밤의 불빛(모닥불·등불·횃불·창문).
- 그 밖에: 능력치(힘·체력·민첩·지능), 스킬 52개, 장비 4칸 × 6단계 × 품질 3단계, 대장간·은행·마탑·후원, 필드 6곳, 암살자 길드 토벌. v0.1·v0.2 저장은 자동으로 옮겨진다.

## 개발

| 경로 | 내용 |
| --- | --- |
| `src/` | 게임 코드: 데이터(`data*.js`), 도트 그래픽(`sprites.js`·`plans.js`·`art.js`·`bg.js`), 시뮬레이션(`core.js`·`econ.js`), 화면(`ui.js`·`view.js`·`panels.js`) |
| `build.py` | `dist/play.html`(한 파일)과 `dist/web/`(설치형 웹앱)을 만듭니다 |
| `tools/android_res.py` | 안드로이드 아이콘과 시작 화면을 `android-res/`에 만듭니다 |
| `.github/workflows/` | `main`에 올리면 웹 배포와 APK 빌드가 자동으로 돌아갑니다 |

```
pip install fonttools brotli pillow
python3 build.py
```
