# 오물거리 상단

몬스터 부속품을 다루는 상단을 키우는 방치형 도트 경영 게임입니다.

파로스 제국의 제도 하르겐. 범죄자가 우글거리는 7번가 오물거리 입구에 작은 상단을 열고, 모험가를 고용해 필드와 던전에서 부속품을 모아 오고, 그것을 팔아 상단을 키웁니다. 매달 말에는 암살자 길드가 자릿세를 받으러 옵니다.

## 플레이하기

- **웹 (아이폰·안드로이드·PC):** GitHub Pages 주소에서 바로 플레이할 수 있습니다.
  - 아이폰: Safari로 열고 공유 → 홈 화면에 추가
  - 안드로이드: Chrome으로 열고 메뉴(⋮) → 앱 설치
  - PC: Chrome이나 Edge 주소창 오른쪽의 설치 버튼
- **안드로이드 설치 파일(APK):** [최신 릴리스](../../releases/latest)에서 `ohmulgeori-sangdan.apk`를 받아 설치합니다.

진행 상황은 기기에 저장됩니다. 앱을 닫아도 최대 2시간(마탑 연구로 늘릴 수 있음)까지는 원정과 상점 판매가 계속되고, 게임 속 날짜는 게임을 켜 둔 동안에만 흐릅니다.

## 지금 들어 있는 것 (v0.2)

- 모험가 능력치: 힘(공격력)·체력(HP)·민첩(회피·공격속도·이동속도)·지능(MP·마법력). 파티 이동속도는 가장 민첩한 모험가를 따릅니다.
- 스킬 28개: 직업과 배울 수 있는 레벨이 정해져 있고, 대부분 MP를 쓰며 몇몇은 HP를 깎아 씁니다. 스킬북을 주워 훈련소에서 배웁니다(최대 4개).
- 장비: 무기·방어구·장신구·가방 4칸, 6단계(견습~사막왕) × 품질 3단계(일반·고급·희귀). 대장간에서 만들거나 원정에서 줍고, 상점에 진열하거나 장비 주문 의뢰에 납품합니다.
- 시설: 상점·여관·훈련소(능력치 훈련, 스킬 배우기)·연금술 공방·대장간·은행(예금과 대출)·마탑(연구 7가지)
- 후원 5곳: 무료 진료소·모험가 길드·하르겐 시민회·드워프 광산 조합·세계수 수호대
- 필드 6곳과 각 던전: 평원·원시림·검은바위산·바람계곡·만년설산·사라크 사막
- 암살자 길드 토벌: 조건을 채우면 7번가 뒷골목의 은신처를 칠 수 있고, 성공하면 자릿세가 사라집니다.
- 최대 4개 파티 동시 파견, 옆모습 행군과 자동전투, 1-10까지 밀면 열리는 던전, 복귀하는 길의 전투, 짐 무게 제한, 영구 사망(동료의 장비는 들 수 있는 만큼만 챙겨 옴)
- v0.1 저장은 자동으로 옮겨집니다(모험가 능력치는 지금 레벨에 맞춰 새로 정해짐).

## 개발

| 경로 | 내용 |
| --- | --- |
| `src/` | 게임 코드: 데이터(`data*.js`), 도트 그래픽(`sprites.js`·`plans.js`·`bg.js`), 시뮬레이션(`core.js`·`econ.js`), 화면(`ui.js`·`view.js`·`panels.js`) |
| `build.py` | `dist/play.html`(한 파일)과 `dist/web/`(설치형 웹앱)을 만듭니다 |
| `tools/android_res.py` | 안드로이드 아이콘과 시작 화면을 `android-res/`에 만듭니다 |
| `.github/workflows/` | `main`에 올리면 웹 배포와 APK 빌드가 자동으로 돌아갑니다 |

```
pip install fonttools brotli pillow
python3 build.py
```
