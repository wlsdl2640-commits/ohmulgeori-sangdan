# 빌드 40 시안: 전사 공격 동작 여러 장 · 십자 방패

- `anim.js`: 시안 그리기 (게임 코드 위에 얹어 돌린다). 몸·머리·다리는 지금 그림을 뭉툭 칸으로 줄이고, 팔·손·칼·방패는 뭉툭 칸 위에 직접 그린다.
  - 동작 표 `AN_M`: 내려베기 · 올려베기 · 횡베기 · 찌르기 · 방패 밀기 · 방패 막기 (8장씩).
  - 한 장: h = 손(어깨에서) · a = 칼 방향(도) · k = 칼 길이 · lean · cr · legs · dx · sh(방패) · fx(효과).
  - 횡베기는 칼끝이 납작한 타원을 돈다 (`th`).
  - 앞에 겹치는 칼날·방패는 몸과 맞닿는 칸에 어두운 테.
- `render.py`: GIF · 장면 띠. `kinds.py`: 방패 다섯 종류 게임 그림. `shields_icons.py`: 목록 그림(16×20) 시안.
- 돌리기: 스크래치의 `sky31/harness.py`(build_html)가 필요하다.
