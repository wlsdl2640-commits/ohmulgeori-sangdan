# 뭉툭 도트 스킬 아이콘 시안 — 307개 전부 (게임에 아직 안 넣음)

지금 쓰는 육각 틀(48px) 안쪽 16×20칸에 한 칸 = 2×2픽셀로 찍는다 (캐릭터와 같은 반 해상도).
배경(속성 색 빛·빛살) + 효과(베기 자국·번쩍·고리, 테두리 없음) + 손그림 상징(검은 테두리 + B4 손질).

- `cell.py` — 판, 배경 계산, 상징 굽기(테두리·부위 사이 선·왼쪽 위 빛·쇠/가죽 질감), 칼·초승달 도우미
- `lib.py` — 배경 색띠(R), 효과(번쩍·별·속도 줄·고리·꼬리·베기 줄), 만들어 그리는 부품(화살·번개·구슬·과녁·구름·결정 창·십자 …)
- `spr.py` — 손그림 상징 모음 (단검·해골·하트·물약·등짐·마차·악기·동물 머리 …)
- `w5.py`, `w9.py` — 전사 15개 · `c_*.py` — 나머지 계열 (계열 묶음마다 한 파일)
- `catalog.py` — 모든 ICONS를 모아 게임 스킬 id 307개와 맞춰 봄 (`python3 catalog.py`), 계열별 시트 (`python3 catalog.py pages2` → sheet_01~05.png)
- `review.py` — 묶음 검토 시트, `look.py` — 8배 칸 눈금 보기
- `data/skills.json` — 게임에서 뽑은 스킬 목록 (id·이름·설명·계열)
- `PLAN.md` — 스킬마다 그림 구상

`cell.py`는 `../chunky/b4.py`를 쓴다.
