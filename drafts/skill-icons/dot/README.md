# 뭉툭 도트 스킬 아이콘 시안 (게임에 아직 안 넣음)

지금 쓰는 육각 틀(48px) 안쪽 16×20칸에 한 칸 = 2×2픽셀로 찍는다 (캐릭터와 같은 반 해상도).

- `cell.py` — 판(16×20칸), 배경 계산(둥근 빛·빛살), 상징 굽기(검은 테두리 + B4 손질: 부위 사이 어두운 선, 왼쪽 위 가장자리 빛, 쇠·가죽 질감), 칼 그리기 도우미, 초승달 자국
- `w5.py` — 전사 기본 5개: 강타 · 도발 1 · 철벽 · 휩쓸기 · 광폭화
- `sheet.py` — 시안 시트 (3배 = 폰에서 보이는 크기, 1배 = 실제 크기): `python3 sheet.py w5 out.png "제목"`
- `look.py` — 8배 칸 눈금 보기
- `dot_draft1.png` — 1차 시안

`cell.py`는 `../chunky/b4.py`를 쓴다 (`sys.path`에 `skicon` 폴더 — 보관본에서는 `chunky/`).
