# 참고 그림 느낌 스킬 아이콘 시안 (3차, 아직 게임에 안 넣음)

- 사용자 요청: 가져온 둥근 스킬 그림들을 참고해 색감·형태를 구성, 틀은 지금 쓰는 육각 틀 그대로.
- 틀 안을 속성 색 빛살(rays)·별 터짐(burst)·소용돌이(swirl)·불꽃(flame)·둥근 빛(glow)으로 채우고(rbg.py), 가운데에 뭉툭 상징(chunky/n1~n6.py)을 얹는다.
- 색 고르기(rpick.py): 속성 스킬은 속성 색, 아니면 직업 계열 색(전사 빨강, 궁수 초록, 도적 보라, 짐꾼 갈색, 성직자 금, 마법사 남보라). 상징과 배경이 같은 색이면 배경을 누르거나(밝은 상징) 밝혀서(어두운 상징) 대비를 만든다. 속성 아닌 스킬은 대비되는 다른 색으로 바꾼다.
- A안: 배경도 2배 굵은 픽셀, B안: 배경은 1배 고운 픽셀. rfull24_*.png는 A안 전체.
- 다시 그리기: chunky/의 n*.py·b4.py와 이 폴더 파일, 상위 폴더 art.py·draft.py·spec.py·clsnames.json, 한 단계 위 skills_dump.json을 모아 `python3 rfull.py 24` (B안은 48).
