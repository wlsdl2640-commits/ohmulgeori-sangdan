# 안건 0 · 로드맵 앞에 넣을 세 가지 기준 — 최종 합의안

## 1. 한 줄 요약

길드장이 층마다 다른 미궁을 개척하고 전리품을 실어 와 길드를 키운다.

## 2. 정한 것

아래 수치는 앞으로 모든 안건과 작업을 점검할 **기준 목표**다. 아직 의견이 갈리는 항목은 3번 「고를 것」에서 사용자가 고른 뒤 확정한다.

### 디자인 기준

등장물의 크기는 **가로 전투 화면 안에서 같은 바닥선**에 놓고 잰다. 원본 그림의 칸 수와 화면에 뜨는 크기를 따로 관리한다.

| 대상 | 지킬 기준 |
|---|---|
| 길드원 | 새 궁수처럼 옆모습, 2.5등신 안팎. 원본 키 **50~87칸**, 화면에 뜨는 키는 **전투 영역 높이의 18~25%**. 검은 외곽선 `#060608`을 원본에서 **1~2칸**, 부위별 명암은 **3단계**로 쓴다. |
| 몬스터 | 화면에서 길드원 키의 **0.7~1.3배**(작은 들짐승은 0.5배, 대형 몬스터는 1.5배까지 예외). 외곽선·명암·점 굵기를 길드원과 맞추고, 실루엣에 그 층의 생태 특징을 **하나 이상** 넣는다. |
| 보스 | 화면에서 길드원 키의 **1.4~2.2배**가 기본(초대형·레이드 보스 예외). 몸과 공격 효과가 아군, 체력 막대, 위험 칸을 가리면 자세나 배치를 조정한다. |
| 배경 | 먼 경치·가운데·땅 **세 겹**, 층마다 주색 **2개**, 강조색 **1개**. 인공 태양·달로 낮밤이 바뀌어도 전투 바닥은 밝기 차를 줄여 캐릭터와 막대가 묻히지 않게 한다. 구름 바다·부유섬의 높이 차와 비행선이 구름 속으로 잠수하는 모습은 겹침과 명암으로 보여 준다. |
| 아이콘 | 새 작은 그림은 **32×32칸, 4~8색**, 큰 물품·기술 그림은 가로세로 **64칸 안팎**을 기준으로 삼는다. 등급과 상태는 색을 빼도 테두리·보석 수·모양으로 구분한다. |
| 전투 효과 | 한 효과에 **2~4색**, 일반 타격은 **0.5초 이내**. 빛은 뭉개지 않고 경계가 또렷한 도트 계단 고리로 그린다. 위험 칸은 **붉은 테두리와 바닥 무늬**로 함께 알린다. |
| 화면과 메뉴 | 어두운 바탕에 일반 강조색 **2개 이내**. 위험 빨강 `#e0503f`는 경고에만 쓴다. 바탕에 `#ff0000`, `#00ff00` 같은 순색을 피한다. 기준 시안 글자는 **11칸 이상**, 그림 위 글자에 검은 그림자 **1칸**을 둔다. |

국기·실제 종교 상징(십자가·초승달과 별 등)·적십자 표장처럼 보이는 도형과 다른 작품의 고유 설정·이름은 쓰지 않는다. 약 10개 층이 이어지는 **미궁 속 하늘**은 날개·흰 구름·빛·금빛 분위기로만 그린다. **안전지대 마을**의 풍경은 층마다 다르게 하되, **화물용 엘리베이터**는 [기획서 요약](../ref_plan_1123.md#L39-L43)의 표준 외형(가운데 마법사의 돌·바깥 화물 플랫폼 약 8기)을 공통으로 쓴다.

### 현행과 부딪치는 곳 (저장소 직접 검증 결과)

- **그림** — 현행 전투 창 높이는 **120칸**이고 새 길드원 그림은 꺼져 있다([전투 화면](../../src/view.js#L4), [길드원 그림 전환](../../src/hd70.js#L208)). 원본 50~87칸 그림을 그대로 쓰면 창 높이의 **42~73%**가 되므로 표시 배율이나 화면 해상도를 손봐야 한다. 들것의 `#e0503f` 붉은 십자([들것 그림](../../src/view.js#L699))는 붕대 매듭 모양으로 바꾸고, 치유 시 뜨는 `+` 입자([치유 효과](../../src/view.js#L1197))도 붉은 물약 색과 겹쳐 적십자처럼 보이지 않게 점검한다.
- **전투·성장** — 현행은 기본 공격 대기 **8초**(최소 1.5초) · 실행 **1.5초**인 실시간 전투이며([전투 수치](../../src/data-rpg.js#L96)), 전멸 시 짐·획득 장비·물약을 잃고 전원이 중상을 입는다([전멸 처리](../../src/core.js#L1521-L1538)).
  - **레벨 역전·경험치 병목**: 1층 끝 **30레벨**에서 2층 초입 **9레벨**(2-50 끝 21레벨)로 떨어지고, 갈래 깊은 숲(22~34) · 뿌리굴(35~45)과도 맞물리지 않는다([필드 설정](../../src/data.js#L199-L261)). 필요 경험치는 `30×레벨^1.8`이라 1→30레벨에 **약 14만 1,665**가 들지만([경험치 식](../../src/core.js#L33)), 처치 경험치는 `몬스터 레벨×3`이고([처치 보상](../../src/core.js#L1353)) 50칸 한 바퀴 처치 수가 약 90~110마리(총 경험치 약 5,000 안팎)라 현행대로면 1층을 **25~30회** 이상 돌아야 30레벨에 닿는다.
  - **장비·상한 격차**: 장비 드랍은 꺼져 있고 제작·구매만 열려 있으며([드랍 비활성](../../src/data-store.js#L23)), 제작은 현실 시간(30초~15분)이 걸린다([대장간 제작](../../src/forge72.js#L9-L21)). 장비 등급 9단계(**1~6.5배**, [등급 표](../../src/data-rpg.js#L459-L469))와 강화 +30(**+90%**, [강화 수치](../../src/enh72.js#L10-L28))이 겹치면 기본 능력치만 **최대 12.35배** 차이가 난다. 능력치 상한은 확률 **50%** · 감소 합 적용 후 남는 피해 하한 **20%**로 잡혀 있다([상한 표](../../src/data-cap69.js#L12-L19), 단 막기 발동 시 4분의 1 감소는 따로 곱해짐 — [피해 계산](../../src/core.js#L1310-L1311)).
- **재화** — 상점 진열대와 자릿세는 꺼져 있고 협회 시설은 무료다([상점 꺼짐](../../src/assoc72.js#L6), [자릿세 꺼짐](../../src/econ.js#L1115)). 협회 일반 판매가는 기준가의 **70%**(랭크·후원으로 소폭 상승, [판매 비율](../../src/econ.js#L691)), 하루 4건 붙는 협회 의뢰(10~50개 납품)는 판매가의 **1.5배** 골드와 **2배** 길드 명성을 준다([협회 의뢰](../../src/assoc72.js#L7-L13)). 마정석과 고유·등급 부속품, 마물육은 필수 드랍이지만 짐꾼 계열이 없으면 갈무리 시간이 2배, 마정석 외 드랍률이 **30%**로 준다([갈무리](../../src/job72.js#L14), [필수 드랍](../../src/mat72.js#L12)). 반면 전사 1명 월급은 **1레벨 120골드 → 100레벨 약 2.1만 골드 → 200레벨 약 8.7만 골드**로 오르고([봉급 식](../../src/data-sal69.js#L7-L13)), +30 강화 1회는 **5만 2,500골드**와 최상급 마정석 5개(+16부터 파괴 확률 1~20%, 에테르 주괴로 방지)가 든다([강화 비용](../../src/enh72.js#L10-L28)).
- **시간** — 층당 50칸, 한 칸 길이 70, 걷기 세 배 보정 규칙 아래([이동 거리](../../src/data.js#L10), [걷기 보정](../../src/data-stat69.js#L11)) 늘 **1-1 재출발**을 유지하면 100층까지 이미 깬 필드만 **24만 7,500칸**을 지나 **5배속으로도 걷기만 약 223시간**이 걸린다. 자리 비움은 기본 **2시간**(연구로 연장) 제한 안에 실제 세계 틱을 돌려 보상한다([자리 비움](../../src/core.js#L1215-L1225)).
