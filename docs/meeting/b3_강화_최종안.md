# 다시 회의 3 · 강화 난이도와 연출 — 최종 합의안

## 1. 한 줄 요약

본편은 **190급 일반~희귀 장비 +0~+7과 파티 전원 4차 전직**으로 100층을 깰 수 있게 두고, +30은 수정 C안을 바탕으로 **+26부터 성공 1%포인트를 파괴로 옮기고 +29·+30에 95층 재료를 더한 C안**(보호·촉매 사용 시 장비 한 벌 원정 **17.65시간**)으로 시험하며, 대장간 공통 바탕과 컴퓨터·모바일 두 벌 화면 위에 투명 효과 그림을 겹쳐 그린다.

## 2. 정한 것

사용자 결정 묶음(원천물·마석 폐기, +1~+30, 성공·보존·실패(−1)·파괴 네 결과, +3까지 성공만, 파괴 방지·성공 확률 보조품, 본인 귀속 강화권 추출, 스팀 장터 다섯 품목, 13장 수정 C안 소폭 상향 및 연출 규격)을 따른다. 아래 수치는 시험 기준값이다.

### 바뀐 점 요약 (앞 합의안 → 새 합의안)
- **바뀜: 등급별 마정석 강화 → 층별 몬스터 부산물 강화.** 마정석은 협회 매입과 일반 장비 제작용 미궁 전리품으로 남긴다(보호품 기초 재료에 쓸지는 「고를 것 ②」로 분리).
- **바뀜: 수정 C안 그대로 시험 → +26~+30 확률 1%포인트 하향 + 95층 깊은층 재료 추가(C안).** 세 난이도 안(A/B/C)의 계산을 비교해 C안을 합의 추천한다.
- **바뀜: 보호품 「에테르 주괴」(40층 15%·70층 35%, +22~+25 엄니 2개) → 「보호 덧쇠」(40층 35%·70층 35%, +22~+25 엄니 1개).** 70층에 몰리던 원정을 40층과 나눈다.
- **바뀜: 화면별 배경 두 벌 → 공통 대장간 바탕 1장 + 컴퓨터·모바일 가로 배치 두 벌.**
- **새로 정함:** 강화 진행 시간(초당 12장), 4종 결과 연출, 픽셀랩 연출 시안 목록을 확정했다.

### ③ 강화권 · 스팀 장터 · 대장간 규칙 (유지)
- **강화권 추출·적용:** `+1` 이상 장비에서 추출하면 장비는 `+0`이 되고 본인 귀속 **`+N 강화권`**을 얻는다. 같은 착용 칸의 `+0` 장비에 적용하며 적용비는 0골드다. 추출비는 `300 + 수치×100`, +8부터 `+(수치−7)²×100`을 더한다(**+7은 1,000골드, +30은 56,200골드**). C · 둘 다로 가죽옷에서 올려 옮기면 추출비 포함 평균 **1,223,620골드**다(받는 190급 장비 확보비 별도).
- **제외·합성:** **가방**과 소모형 장비(**화살·볼트·표창**)는 강화·강화권 대상에서 제외하고, **장비 9개 합성**은 `+0`만 넣는다.
- **스팀 장터 다섯 품목:** **기본 완제품(+0) · 강화 재료(부산물) · 제작 재료 · 보호품(덧쇠) · 추출한 +0 장비**만 거래한다(추출 +0 장비는 룬 회수·무작위 보너스 제거 후 순정 동종 품목으로 합침). 강화권·촉매·내열 비늘·골드는 귀속이다.

### ④ 강화 화면과 연출
- **화면 두 벌:** 공통 대장간 바탕 1장 위에 **강화 / 강화권 추출·적용 / 장비 합성** 전환을 둔다. 현재 수치·능력치, 성공 시 목표 수치·능력치, 보조품 반영 후 네 확률을 항상 표시한다.
  - **컴퓨터 (16:9):** 왼쪽 장비 목록, 가운데 모루와 능력치 비교, 오른쪽 확률·재료·보조품·강화 버튼.
  - **모바일 가로 (20:9):** 왼쪽 모루, 오른쪽 확률과 재료. 장비 목록은 접어서 열고, 아래에 보조품과 강화 버튼을 고정한다. 넓은 화면 양옆에는 확장 배경을 보여 준다.
- **파괴 위험 확인창:** 파괴 확률이 0%보다 크면 강화 버튼을 누른 뒤 장비 이름·파괴 확률·덧쇠 상태를 확인창에 띄운다(덧쇠 2개 구간에 1개만 넣었을 때도 포함).
- **진행 시간(초당 12장):** **+1~+17은 0.75초**(타격 5+결과 4), **+18~+25는 1.08초**(타격 7+결과 6), **+26~+30은 1.42초**(타격 9+결과 8), **+30 성공은 1.58초**(타격 9+전용 10)다. 타격 불빛은 주황 → 푸른빛 → 보라·흰빛 → 금빛으로 커진다. 빠른 연출은 **0.35초**로 줄이고, 결과 글과 수치는 다음 조작 전까지 남긴다. (C · 둘 다 경로의 기본 연출 총 재생은 약 2분 40초다.)
- **네 가지 결과 연출 (이펙트는 장비 그림과 분리해 겹쳐 그림):**
  - **성공:** 금빛 불티가 위로 솟고 새 수치가 뜬다. +30은 전용 금빛 마무리 연출이 붙는다.
  - **보존:** 옅은 푸른빛이 퍼지고 수치가 고정된다. 덧쇠가 파괴를 막으면 푸른 방어 막이 갈라지며 **보존 · 보호 발동**을 띄운다.
  - **실패:** 주황 불씨가 모루 아래로 떨어지고 수치가 한 칸 내려간다.
  - **파괴:** 붉은 균열과 잿가루가 퍼지고 장비 자리가 비며 사라진 장비 이름을 남긴다.

## 5. Claude에게 넘길 메모

- **확인 필요 (시험값 실측 항목):** 40·70·77·95층 배치, 전투당 출현 횟수, 회수율, 순골드, 190급 장비 실제 제작비는 브리핑 기준 시험값이다. 원시림이 4층으로 이동하면 `철갑 풍뎅이 겉껍질`도 함께 옮긴다. 시험 빌드에서는 **+7 평균 비용**, **+30 평균 및 90% 도달 횟수**, **다수 파티 동시 원정 시 실제 경과 시간**, **+1~+30 구간별 능력치 배율 곡선**을 확인한다.
- **코드·데이터:** 강화 결과(수치 변화·재료/보조품 차감·보호 발동)를 먼저 확정 저장한 뒤 연출을 재생한다. 추출·적용도 장비와 강화권을 원자적으로 함께 처리한다. 가방과 화살·볼트·표창은 강화·강화권 대상에서 빼고, 장비 9개 합성은 `+0`만 받는다. 추출·적용 및 합성 화면의 짧은 빛 연출은 기존 결과 그림 재활용 여부를 추후 정한다.
- **장터:** 기본 +0 장비·강화 부산물·제작 재료·보호 덧쇠·추출한 +0 장비의 다섯 품목만 연다. 추출 장비의 룬 회수 및 무작위 옵션 제거 전에는 사라질 능력치를 미리 경고한다. 모바일 시험 빌드에서는 스팀 지급·장터 메뉴를 감춘다.
- **폐기 목록:** 원천물·마석 강화식, 등급별 마정석을 직접 소모하던 강화식, 에테르 빛가루 기반 보호 주괴 제작식, 마정석을 넣던 계산용 가죽옷 제작식.
