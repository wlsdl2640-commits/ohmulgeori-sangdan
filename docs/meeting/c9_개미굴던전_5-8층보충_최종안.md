## 5. Claude에게 넘길 메모

- **그림 순서와 양** — 1층 데모 완료 뒤 **굴귀뚜라미·굴방 → 굴 일반 5종 → 5층 3종 → 8층 3종** 순으로 진행한다. 정지 시안은 일반 11종 × 2장, 주인 4장, 대표 배경 3장으로 **약 29장**이다. 승인 뒤 일반은 각 4동작(대기·이동·공격·쓰러짐), 주인은 6동작(대기·이동·발차기·전환·땅울림·쓰러짐)으로 **총 50동작**을 잡는다. 배경은 마른 틈·젖은 굴·울림 굴방의 **3묶음 × 3겹**에 돌판·균사·물길 소품을 바꿔 10장면을 만든다. 새 계층 작업 시작 전에는 대표님에게 계층 이름을 확인한다.
- **분기 처리** — 입장 시 3-14의 본길 진행 위치를 저장하고, 완료·철수·재접속 때 이어지게 한다. 귀환 직후 같은 입장 창이 다시 뜨거나 재접속으로 보상이 중복 지급되는 경우를 시험한다. 선택 화면은 컴퓨터용·모바일용 두 벌로 만든다.
- **확인 필요** — 11-23 기획서 원문, 3층 그림 15종의 출현 구분, 여왕 수치와 보상, 5·8층 기존 5종의 기술과 공용 부속품, 숫돌·주문서의 기존 공급량. 특히 5층 중독·공격 봉쇄와 8층 눈멂·회복이 기존 종과 겹치는지 **그림 발주 전에** 대조한다. 두 명 타격, 마력 대상 선정, 상태이상 중첩 처리는 현재 전투 기능에서 확인한다.
- **폐기 목록** — 없음. 이끼털 들쥐는 후보로 보관한다.
