# 안건 13 · 자동 원정 흐름 · 플레이어 개입 선택지 · 야영 시스템 최종 합의안

## 1. 한 줄 요약

길드장이 출발 전에 행군 방식·보급·물류·철수 방침을 정해 두면 원정대가 전투·갈무리·야영·하역·비콘·회수를 끝까지 자동으로 돌리고, 플레이어는 중요한 길목 예고와 수시 개입으로만 방향을 바꿀 수 있게 한다.

---

## 2. 정한 것

### ① 원정 한 번의 자동 흐름 (방치 · 오프라인에서도 끝까지 순환)

```text
본부 정비 (체력·부상·피로 회복, 보급 주머니·비콘 도구 확인, 회수 임무 시 지상 창고 칸 예약)
  ↓
출발 (기본: 1층 1-1 출발 · 일반 행군 / 1-50 첫 처치 후 빠른 돌파 선택 / 승인 시 열린 마을 유료 워프)
  ↓
한 칸 이동 (이동 시간·낮밤·보급 소모)
  ├─ 1) 도착 지점 판정
  │    ├─ 안전지대 마을 → 방침·여력에 따라 들러서 하역·정비·야영 또는 통과
  │    ├─ 보스방·샛길 입구 → 목표·방침 확인 (100층 보스는 전원 4차 직업일 때만 도전)
  │    └─ 회수 목표 지점(비콘·협회 창고) → 비콘 길목 재전투 후 실을 만큼 적재 → 귀환 전환
  ├─ 2) 칸 전투 및 갈무리
  │    ├─ 빠른 돌파 대상인 이미 돌파한 일반 칸 → 일반 전투·갈무리 생략
  │    └─ 일반 행군·새 길·목표 전투·비콘 재전투 → 자동 전투 → 여력 있으면 갈무리
  │         (인물·단서 발견 시 전투·이동을 끊지 않고 수첩에 한 줄 기록 → 귀환 후 이야기 함)
  ↓
전투 후 상태 판정 (다음 행동 결정)
  ├─ [최우선] 들것 발생 · 숙면 피로 85 이상 · 생존 여력 부족 → 즉시 귀환 전환
  │    └─ 들것 운반 불가(과적 계속 시 새 수습 중단 후 느린 귀환) · 전원 쓰러짐 → 협회 구조 · 치료
  ├─ 짐이 참 → 앞뒤 마을 비교(이동 시간·남은 전투·보급·창고 칸; 비슷하면 지나온 마을)
  │    ├─ 마을 이동 유리 → 마을 하역(엘리베이터·협회 창고) 후 탐험 계속
  │    └─ 마을까지 멀고 지정 길목·조건·보관 한도 충족 → 비콘 설치(도구 1개) 후 탐험 계속
  │         └─ 하역·설치 모두 불가 → 허용 품목만 최소 정리(알·의뢰품·보호품·미감정품 제외) 후 안 되면 귀환
  ├─ 한밤중 회복 필요(체력·피로·보급·다음 구간 위험 기준) → 야영 → 새벽에 상태 재확인
  └─ 목표 달성·복귀 지시 → 귀환 / 그 외 → 다음 칸 이동
  ↓
귀환 (안전지대 도달 + 예산 내면 워프 귀환, 그 외 직접 귀환)
  ↓
지상 정산 (짐 정리 · 창고 포화 시 임시 하역장/파티 보유 대기 · 원정 결과 및 「이야기 함」 갱신)
  ↓
본부 정비 → 자동 재출발 조건 충족 시 다시 출발
```

| 단계 | 자동 처리 규칙 |
|---|---|
| **본부 정비** | 부상·체력·숙면 피로가 출발 기준까지 회복되면 정해 둔 꾸러미를 챙긴다. 주방 도시락·물약·화살·볼트·암기는 **보급 주머니**에 넣어 전리품 칸을 차지하지 않고 무게에만 더한다. 비콘 도구는 구매 허용 시 예산 안에서 보충한다. 필수 보급이나 받을 창고 칸(회수 시)이 부족하면 이유를 남기고 대기한다. |
| **전투 · 갈무리** | 전투는 자동 진행하며, 플레이어 응답을 기다리며 멈추지 않는다. 짐꾼 계열만 가방을 착용하고 5대 숙련(운반술·정리술·해체술·감정술·경량화)을 쌓는다. 짐꾼 없는 파티는 **갈무리 시간 2배, 마정석 기본 수습, 그 외 전리품 획득 확률 ×30%**를 적용한다. |
| **회수 임무** | 최대 6파티 중 기존 파티 한 팀에 회수 임무를 부여한다(임무 중 일반 탐험 휴식, 중복 편성 불가). 출발 전 지상 창고 칸을 예약하고, 열린 빠른 돌파 구간을 써서 비콘·협회 창고로 이동한다. 한 번에 못 실으면 잔여 짐은 그 자리에 남기고, 회수대 패배 시 확보한 짐은 **마지막 확보 지점**에 남겨 재회수한다. |
| **하늘 · 도보 연계** | 39층에서 협회 기본 비행선을 빌리거나 길드 비행선으로 39~48층을 항해한다(43층 구름닻 마을 출발 시 비행선 먼저 확보). 48층 보스 뒤 내려 49~51층은 도보 이동하고, 52층 마을부터 다시 마차 거점으로 쓴다. 귀환 회수대는 52층에서 49~51층을 나누어 걸어 나른 뒤 하늘 구역 진입 시 비행선에 옮겨 싣는다. |
| **귀환 · 정산** | 들것 1명당 적재 한도 **15 차감**. 지상 창고 칸이 부족하면 엘리베이터·회수 화물은 해당 승강탑 **임시 하역장**에 두고 비울 때까지 그 탑의 다음 운송을 멈추며, 직접·워프 귀환 짐은 창고 자리가 날 때까지 파티가 보유한다. |

### ② 안건 6(물류 · 비콘) · 안건 7(빠른 돌파) · 안건 4(이야기) 연결 위치

| 앞 안건 규칙 | 자동 원정 흐름에서 들어가는 자리 |
|---|---|
| **안건 7 · 빠른 돌파** | **출발 선택 & 한 칸 이동:** 1-50 갑옷 멧돼지 첫 처치 뒤 다음 1-1 출발(및 회수 임무)부터 선택 가능. 이미 돌파한 일반 칸은 전투·갈무리(경험치·전리품 0)만 건너뛰고, **이동 시간·낮밤·보급 소모·야영·새 길·보스방·샛길·비콘 길목 재전투**는 그대로 진행한다. 길드 랭킹은 출발 지점과 행군 방식이 같은 기록끼리 비교한다. |
| **안건 6 · 마을 · 창고 · 엘리베이터 · 워프** | **마을 도착 & 하역 & 귀환:** 마을 10곳(3·11·22·34·43·52·62·73·84·95층 초입)에 직접 닿아야 열린다. 마을에서는 엘리베이터(생명체 불가, 알 가능)나 협회 창고(마을별 무료 60칸·유료 초과·최대 120칸, 자동 전송 없음)에 짐을 두고 탐험을 잇거나, 예산 내 워프 귀환을 쓴다. |
| **안건 6 · 비콘** | **위험 길목 짐 포화:** 안전지대 밖 지정 길목 전투 승리 후 일회용 도구 1개로 설치(최대 12칸·무게 60, 길드당 2곳·길목당 1곳, 보호 24일 또는 48일 미결). 보호 시간은 오프라인 한도(기본 2시간, 마탑 연구 연장 가능)를 넘어 게임이 멈춘 동안에는 함께 정지한다. |
| **안건 4 · 이야기와 인물** | **이동·야영 중 발견 & 귀환 정산:** 원정 중 인물·단서 만남(예: 19층 빛이끼 수정굴 단석의 밤 관찰)은 한 줄로 기록만 남기고 진행을 끊지 않는다. 낮에 지나쳐도 해당 층 도달 기록이 있으면 귀환 뒤 「이야기 함」에서 밤 관찰 기록으로 이어져, 특정 밤을 억지로 기다리지 않는다. |

### ③ 플레이어가 개입하는 선택지 목록과 알림 · 방치 처리

- **예고 기준:** 길목 **3~5칸 전**(시험 기준)에 먼저 띄우고, 그보다 가까운 위치에서 처음 파악되는 선택은 즉시 띄운다.
- **무응답 · 방치 · 오프라인:** 길목에 닿을 때까지 답이 없으면 **출발 전에 정해 둔 방침**대로 자동 선택한다. 오프라인에서는 같은 방침으로 최대 한도(기본 2시간, 마탑 연구 연장)까지 처리한 뒤 접속 시 파티별 결과를 묶어 보여 준다.
- **수시 개입:** 예고와 별개로 플레이어가 원정 화면을 보고 있을 때는 언제든 **다음 안전 시점 복귀 · 즉시 귀환 전환 · 자동 방침 수정**을 누를 수 있다.

| 개입 순간 | 플레이어가 고를 수 있는 선택 | 답이 없을 때 (기본 자동 방침) | 기본 알림 설정 |
|---|---|---|---|
| **1. 출발 준비** | 일반 행군 / 빠른 돌파, 일반 탐험 / 회수 임무, 보급 꾸러미, 워프·비콘 예산 상한, 자동 재출발 | 저장한 방침 적용 (미해금 시 일반 행군) | 출발 화면 |
| **2. 안전지대 접근** | 들러서 하역·정비·야영 / 멈추지 않고 본길 계속 | 처음 닿는 마을이거나 하역·정비·야영이 필요하고 여력이 있으면 들름 | 첫 방문만 켬 |
| **3. 마을 하역 방법** | 화물 엘리베이터 / 협회 창고 보관 / 직접 운반 / 워프 귀환 | 창고 예약·용량·요금 상한을 확인해 저장한 우선순위대로 처리 | 끔 |
| **4. 위험 길목 짐 포화** | 비콘 설치 후 계속 / 앞·뒤 마을로 이동 / 귀환 | 설치 허용 + 회수 가능 전망이면 비콘, 그 외에는 마을행 또는 귀환 | 켬 |
| **5. 보스방 · 샛길 입구** | 도전·탐색 / 본길 계속 / 귀환 | 목표로 정한 곳만 진입. 필수 보스는 생존 여력 확인, **100층은 전원 4차 직업**일 때만 진입 | 보스방 켬, 샛길 끔 |
| **6. 철수 기준 근접 · 만료 임박** | 다음 안전한 시점에 미리 복귀 지시 / 행군 방침 유지 | 들것·피로 85·여력 부족 도달 시 즉시 자동 귀환 전환(귀환 중 위험 시 가까운 곳에서 쉼) | 귀환 전환·비콘 만료 임박 상태 알림 |

- **두 화면 구성 (같은 방침 공유, 화면 두 벌 저장):**
  - **컴퓨터용:** 지도 오른쪽에 다음 선택 예고, 시간 초과 시 자동 선택될 답, 예상 워프 요금·이동 시간·비콘 남은 보호 시간을 상시 표시.
  - **모바일 가로용:** 전투·이동 시야를 가리지 않도록 화면 아래 한 줄 요약 막대와 큰 선택 단추만 띄우고, 요금·시간 비교는 눌렀을 때만 펼침.

### ④ 야영 시스템 세부 규칙

- **밤의 두 구간:** 하루는 **1배속 3분**이며 야영 연출도 이 시간 흐름 안에 들어간다. 밤 초반에는 행군·전투·밤 단서 발견을 계속하고, 한밤중에 **체력·숙면 피로·보급·다음 구간 위험도**를 확인해 회복이 필요한 파티만 그날 밤 안에서 한 번 쉰다. 상태가 충분하면 빠른 돌파·일반 행군 모두 멈추지 않고 지나갈 수 있다.

| 야영 단계 | 세부 규칙 |
|---|---|
| **1. 자리 고르기** | 이동 가능한 범위 안에서 **습격 위험 → 비바람 차폐 → 이동 거리** 순으로 자리를 고른다(들것이나 중상자가 있으면 가까운 안전지대·가장 가까운 쉴 자리를 우선한다). 가까운 안전지대에 닿을 수 있으면 마법사의 돌 보호 반경 안에서 각자 장비로 쉰다(**마을 밤습격 0%**, 여관 없이 원정대 보급 사용). |
| **2. 불 피우기와 도시락** | 도시락은 **1인 1끼**, 체력·피로가 나쁜 동료부터 챙긴다. 화기가 유지되는 자리(맑은 날 또는 지붕·동굴 턱·덮개 마차로 비바람을 막은 자리)에서는 데워 먹어 **체력·피로 추가 회복 및 추위·습기 완화**를 얻는다. 노출된 노천에서 비로 불이 꺼지면 기본 효과만 적용된다. |
| **3. 잠자리와 불침번** | 텐트는 **1채당 2명**, 피로가 높은 동료부터 들인다. 불침번은 **짐꾼 계열(정찰가·탐험가 우선)**이 먼저 서고, 다음 교대는 아직 보초를 서지 않은 동료(짐꾼이 없는 파티는 체력·피로 여유가 있는 동료 순)가 맡는다. 보초도 교대 뒤 쉰 시간만큼 회복한다. 육상 탈것은 내려서 웅크려 잔다. |
| **4. 밤습격과 회복** | 길 위 밤습격은 **파티당 하룻밤에 최대 1회**만 판정한다. 자리·날씨가 기본 위험을 정하고 정찰·텐트가 위험을 낮추며, 보초가 있으면 기습 불이익을 막는다. 습격전은 자동 진행하며 승리 시 남은 시간만 쉬고, 철수 기준에 닿으면 귀환한다. 체력은 쉰 시간과 식사에 따라, 숙면 피로는 쉰 시간과 잠자리(노숙 < 모닥불 < 텐트 < 덮개 마차)에 따라 회복한다. |
| **5. 새벽 재확인** | 날이 밝으면 체력·숙면 피로·보급을 다시 점검해 행군 계속 또는 귀환을 정한다. 비콘과 같은 길목에서 야영해도 **비콘 보호막은 보관한 짐에만 닿고**, 모험가 밤습격 판정은 일반 길목과 같다. |

- **환경별 야영 자리 (기초 유형으로 묶어 100층까지 재사용):**
