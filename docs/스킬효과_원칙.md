# 스킬 효과 원칙 (11-25 · 대표님 참고 영상 40개 + 충격파 「그래 그거야」)

**최소 수준 = 충격파 새 방식.** 효과 그림을 몬스터 · 맵과 같은 그림체로 직접 그리고(픽셀랩 이미지 생성 · 늪지 괴물 그림을 그림체 참고로), 그 그림을 움직이게 만든다(pixminimax). 효과 도구 부품(동그라미 · 고리 · 점 입자)만으로 만든 효과는 쓰지 않는다.

## 참고 영상에서 본 것 (꼴만 배움 · 그림은 베끼지 않음)
1. **단계가 넷**: 모으기(빛이 모임 · 기운) → 터짐(가장 크고 밝은 한두 장) → 퍼짐(조각 · 불꽃 · 먼지가 흩어짐) → 남음(연기 · 불씨 · 갈라진 땅이 천천히 사라짐). 터지는 장은 짧고, 남는 장은 길다.
2. **밝은 심 + 색 테**: 빛나는 것은 가운데가 거의 흰색, 바깥으로 갈수록 진한 색(칼 = 흰 → 쇠빛 파랑 → 호박 테, 불 = 흰 → 노랑 → 주황 → 붉음). 빛나는 것에는 검은 테가 없다.
3. **단단한 것은 테 + 명암**: 돌 · 흙 · 쇠 조각 · 먼지 구름은 몬스터처럼 어두운 테와 3~4단 명암. 그래서 배경 · 몬스터와 섞인다.
4. **큰 모양 하나 + 작은 것 여럿**: 초승달 베기 · 충격 고리 · 기둥 같은 큰 모양 하나가 먼저 읽히고, 그 둘레에 불꽃 · 조각 · 먼지가 겹겹이.
5. **땅을 쓴다**: 땅 위 효과는 납작한 타원(원근)으로 — 마법진 · 충격 고리 · 갈라짐 · 먼지는 땅에 붙는다.
6. **움직임**: 베기는 한 번에 다 나타났다가 가늘어지며 조각나 사라짐. 터짐은 커지며 옅어짐. 기둥 · 기운은 아래에서 위로. 몸이 움직이는 스킬은 위치를 옮김(뛰어들기 포물선 · 돌진 잔상).
7. **크기**: 보통 스킬은 캐릭터 키 0.8~1.5배, 큰 스킬만 화면을 덮음. 화면 전체 번쩍임(흰 화면)은 4차 · 궁극기만.

## 시안을 볼 때 먼저 따질 셋 (11-25 대표님)
1. **필요한 효과인가** — 스킬이 하는 일과 상관없는 장식은 뺀다.
2. **스킬 효과가 눈에 보이는가** — 보는 사람이 「무엇을 했는지」 알 수 있어야 한다.
3. **게임 그림체와 맞는가** — 몬스터 · 맵과 같은 도트 · 테 · 명암.

### 전사 1차 스킬 — 효과가 보여 줘야 할 것
| 스킬 | 하는 일 | 효과가 보여 줄 것 |
|---|---|---|
| 밀어 베기 | 기본 베기 | 칼이 지나간 길(초승달) · 맞은 자리 불꽃 |
| 두 번 베기 | 두 번 친다 | 베기 두 줄이 차례로(X) — 「두 번」이 읽혀야 |
| 내려 베기 | 위에서 내리친다 | 위 → 아래로 떨어지는 베기 · 땅에 닿는 불꽃 |
| 발굽 끊기 | 다리를 베어 느리게 | 낮게 땅을 스치는 베기 · 흙 튐 |
| 가로 휩쓸기 | 여러 적을 한 번에 | 넓은 가로 베기가 적 여럿을 지나감 |
| 되치기 | 막고 되받아친다 | 막는 불꽃 → 바로 앞으로 튀어 나가는 베기(두 박자) |
| 방패 두드리기 | 방패로 쳐서 피해 | 둔탁한 충격(쇳빛 불꽃 · 충격 고리) |
| 방패 밀치기 | 밀어 피해 + 기절 | 앞으로 미는 힘 · **적 머리 위 기절 별** |
| 둥근 방패 막기 | 피해를 막음 | 앞에 선 막 · 막힌 자리 불꽃 |
| 도발 | 적이 나를 노림 | 붉은 외침 고리 · 적 쪽으로 퍼짐 |
| 돌격 함성 | 파티 강화 | 함성 고리 · 동료 쪽으로 퍼지는 기운 |
| 결의 | 자기 강화 · 공포 해제 | 몸에서 솟는 금빛 기운 |
| 자세 고정 | 밀리지 않음 · 방어 | 발밑에 박히는 쇠빛 고리 · 땅에 고정된 느낌 |
| 강철 피부 | 상시 방어(패시브) | **작게** — 맞을 때 몸에 쇠빛 번쩍임 정도면 충분 |
| 대지 가르기 | 앞 일직선 피해 | 앞으로 달려 나가는 땅 갈라짐 · 솟는 돌 |
| 충격파 | 둘레 피해 | 둘레로 퍼지는 땅 충격 · 돌 가시 |
| 뛰어들기 | 뛰어 들어가 착지 피해 | 포물선 이동 + 착지 흙먼지 |
| 방패 착지 | 착지 + 보호막 | 착지 충격 + 몸을 덮는 막 |

## 자연스러움 (11-25 대표님 「프레임 엄청 길게 넣어도 된다 · 먼지가 일다가 끊기거나 갑자기 생기는 건 없어야」)
- 장 수를 아끼지 않는다: 사라지는 쪽 40장 + 생기는 쪽 24장(사라지는 장면을 거꾸로 만든 것이 아니라 「줄어 들어가는」 장면을 따로 만들어 거꾸로 튼다 — 생기는 것도 자라나듯).
- 어느 장에서도 무엇이 갑자기 나타나거나 끊기면 안 된다 — 장 사이 차이가 큰 곳은 사이 장을 섞어 넣고(겹쳐 옅게 바꾸기), 마지막은 투명도를 천천히 내린다.
- 게임에 넣을 때도 효과는 끝까지 다 틀고(동작이 끝나도 먼지는 남아 사라짐) 다음 효과가 와도 앞 효과를 지우지 않는다.

## 차수마다 화려함 (11-25 대표님 「최소치랑 최대치 · 1차는 너무 화려할 것까진 없음」)
| 차수 | 크기 | 단계 | 색 · 빛 | 화면 |
|---|---|---|---|---|
| 1차 (최소치 = 충격파) | 캐릭터 키 0.6~1.2배 (스킬에 따라 화려하게도) | 터짐 · 퍼짐 · 남음 (모으기 짧게) | 색 묶음 하나(쇠빛 · 흙) · 빛 심 작게 ~ 크게 | 흔들림 · 큰 한 방은 짧은 번쩍임도 |

- 11-25 대표님 「1차에도 화려한 걸 좀 넣어 · 다 뒤로 몰지 말고 시안 여러 개로」 → 스킬마다 **A 차분 · B 보통 · C 화려** 시안을 그림으로 먼저 보이고, 고른 것만 움직이게 만든다. 위 표는 기준선일 뿐 고른 시안이 우선.
| 2차 | 0.8~1.5배 | 넷 다 | 직업 색 하나 더 | 큰 한 방만 살짝 흔들림 |
| 3차 | 1~2배 | 넷 다 · 겹 둘 | 빛 심 크게 · 잔불 · 기운 | 흔들림 + 짧은 번쩍임 |
| 4차 (최대치) | 화면 절반 이상 | 넷 다 · 겹 셋 + 마법진 · 기둥 | 강한 빛 · 화면 색 바뀜 | 궁극기만 화면 전체 번쩍임 |
