# 미궁도시 라비린토스 — 로드맵

> 맨 앞 세 가지(정체성 · 디자인 기준 · 밸런스 기준)는 모든 회의 · 작업을 점검하는 잣대다. 지금은 **AI 회의가 만든 제안 — 사용자 확인 전**이다(11-25).
> 출시 목적은 스팀 PC 게임(사용자는 주로 모바일로 테스트 — APK는 모바일 UI, PC 버전은 컴퓨터용) · 맵 · 건물 · UI까지 모든 디자인을 통일한다(11-25).
> 모든 안건 · 결과물은 네 기준으로 점검한다: ① 게임 컨셉에 맞는 디자인 ② 디자인끼리의 통일성 ③ 게임 밸런스 ④ 독창성 · 아이덴티티.

## 0-1. 게임 정체성 한 줄 (제안)
**길드장이 층마다 다른 미궁을 개척하고 전리품을 실어 와 길드를 키운다.**
(후보: A 「…원정대를 꾸려 … 전리품으로 길드를 키운다」 · B 「…원정대와 물류망을 꾸려 백 층 미궁을 개척하는 길드 경영 모험」 — GPT · 제미나이 · Claude 모두 위 문장 추천)

| 대상 | 기준 |
|---|---|
| 길드원 | 옆모습 2.5등신 안팎 · 원본 키 50 ~ 87칸 · 화면 키는 전투 영역 높이의 18 ~ 25% · 외곽선 `#060608` 1 ~ 2칸 · 명암 3단계 |
| 몬스터 | 화면에서 길드원 키의 0.7 ~ 1.3배(작은 짐승 0.5, 대형 1.5배까지) · 외곽선 · 명암을 길드원과 맞춤 · 실루엣에 그 층 생태 특징 하나 이상 |
| 보스 | 길드원 키의 1.4 ~ 2.2배(초대형 예외) · 아군 · 체력 막대 · 위험 칸을 가리지 않게 |
| 배경 | 먼 경치 · 가운데 · 땅 세 겹 · 층마다 주색 2 + 강조색 1 · 낮밤이 바뀌어도 전투 바닥은 밝기 차를 줄임 |
| 아이콘 | 새 그림: 작은 것 32칸 · 4 ~ 8색, 큰 것 64칸 안팎 · 등급은 색을 빼도 테두리 · 보석 수 · 모양으로 구분. 기존 그림은 화면에서 읽히면 유지 |
| 전투 효과 | 2 ~ 4색 · 일반 타격 0.5초 이내 · 빛은 또렷한 도트 계단 고리 · 위험 칸은 붉은 테 + 바닥 무늬 |
| 화면 · 메뉴 | 어두운 바탕 · 강조색 2개 이내 · 위험 빨강 `#e0503f`는 경고에만 · 순색 바탕 금지 · 글자 11칸 이상 |
| 금지 | 국기 · 실제 종교 상징 · 적십자처럼 보이는 도형 · 다른 작품의 고유 설정 · 이름. 미궁 속 하늘은 날개 · 흰 구름 · 빛 · 금빛 분위기로만 |
(손볼 곳: 들것의 붉은 십자 · 치유 `+` 입자 · 새 길드원 그림을 120칸 전투 창에 맞출 표시 배율)

## 지금 할 일 — 순서대로 하나씩 (대표님 11-25 오후)
1. **늪지대 물길 배경 + 3층 개미굴 완성** — 회의(c1) → 픽셀랩 시안(몬스터마다 후보 4 · 여왕개미는 큰 크기 · 문지기 개미 · 늪지 괴물 · 새 슬라임) ← **진행 중**
2. **직업 모델링**: 전사 → 짐꾼 → 도적 → 사제(여) → 마법사(여)(궁수는 끝). 직업마다 ① 행동 프레임 ② 스킬 프레임 ③ 스킬 구성 ④ 스킬 이펙트 — 단계마다 시안 판 → 대표님 고름 → 확정.
3. **몬스터 동작 다시 뽑기**: 섬광 · 베기 자국 · 사람이 그려진 24개 + 남은 19개 — 지시문 「효과 · 섬광 · 사람 없이, 몬스터만」 + 첫 장 · 끝 장에 없던 색이 생긴 장은 자동으로 걸러 다시.
4. **안건 10 ~ 15 새 결정으로 다시 회의**(11 직업 · 14 스킬셋은 직업 모델링과 맞춰) + 세계관 결정(하늘 계층 옮기기 · 폐허 안전지대 · 모래사막 · 오아시스 · 대륙 이름)을 안건 3 · 4 · 12에 반영 + **새 안건: 범죄 조직 둘(암살자 조직 · 「핸드」)** + 배경 생동감 · 길드원 이름 회의.
5. **남은 도시 장면 9장**(배경 생동감 방식 — 움직일 것은 따로 겹침).
6. (직업 모델링 다음, 또는 대표님이 시작하라고 할 때) **워프게이트 · 화물 엘리베이터 · 안전지대 마을 이름 · 컨셉 · 건물 · 협회 물류창고 디자인** — 회의 → 픽셀랩 시안. 공통 시설은 어느 마을에서든 같은 모양, 마을 건물은 층 환경에 맞게, 51층부터는 임시 거점 → 마을로 자라는 단계별 모습.
