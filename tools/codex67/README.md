# 직업별 장비 도감 (빌드 67, 11-13 사용자 「모든 장비들 직업 이미지가 맨 앞에 … 각 직업별 장비들 정보 만들어서 보여줘, 공용장비도 다」)

- 올린 곳: Claude 아티팩트 「판타지상단키우기 장비 도감」 https://claude.ai/artifact/EG7uvz2kNqETAhgcsUshVA
- 다시 뽑기 (게임 자료가 바뀌면):
  1. `BUILD_NO=67 python3 build.py` → `dist/play.html`에 훅(`window.__EV = s => eval(s);`)을 넣은 사본을 만든다
  2. `python3 tools/codex67/extract.py <훅 사본> catalog.json` — 직업(계열 · JOB_TREE 차례) · 직업 그림(그 레벨 대표 무기 · 부장비, 탈것은 타고) · 장비 종류마다 착용 레벨 순 그림 · 이름 · 능력치(일반 등급) · 얻는 곳(떨어짐 · 대장간 · 투기장 · 삼) · 그림만 있는 다음 레벨
  3. `python3 tools/codex67/build_page.py catalog.json gear-codex.html` — 갈무리 글꼴을 쪽에 쓰는 글자만 남겨 넣는다
  4. 같은 아티팩트 주소로 다시 올린다
- 공용 장비(cls all: 벨트 · 반지 · 부적 · 챔피언의 반지 · 귀걸이 · 가방)는 직업 카드에서 빼고 「공용」 탭에만.
- 장비 종류마다 한 장(11-13 09:22 사용자 「한장비종류당 이미지로」): `python3 tools/codex67/cards.py catalog.json <출력 폴더>` → 73장 PNG(가로 1080px — 맨 위에 입는 직업 그림 · 그 아래 착용 레벨 순 그림 · 이름 · 단계 · 능력치 · 얻는 곳 점, 공용은 계열 첫 직업 여섯 + 「모든 직업」). 파일 이름 `NN_칸_종류.png`(차례는 직업 카드의 칸 차례 · 공용은 그 칸 끝). 쪽 `<출력 폴더>/../cards.html`을 함께 만든다.
- 몬스터 · 부속품 · 잡템 그림(11-13 10:02 사용자 「몬스터별, 나오는 부속품, 기타 다른 잡탬들 까지 이미지로 나눠서」): `python3 tools/codex67/mon_extract.py <훅 사본> mon.json` → `python3 tools/codex67/mon_render.py mon.json <출력 폴더>` → 35장 — 몬스터 20장(땅마다 한 장: 함께 나오는 약초 · 펫 알 · 스킬북 단계 몫 · 장비 확률, 필드 몬스터 · 필드 우두머리 · 던전(필드와 같은 몬스터는 이름만) 카드마다 그림 · 다른 모습 · 타입 · 속성 · 부속품 확률 · 값, 우두머리 · 주인 보상(증표 · 핵 · 혼 · 룬 · 돌 · 보물 지도) + 초대형 레이드), 잡템 8장(몬스터가 안 떨어뜨리는 것: 약초 · 식재료 · 요리 · 물약 · 특성 돌 · 보물 지도 · 상단 전용 물건 · 알 · 룬 · 기타 재료 · 교역품 — 얻는 곳 글), 스킬북 7장(단계 책 + 공용 · 계열마다, 배우는 레벨 순).
- 빌드 67 무기 그림 20종(11-13 11:54)을 넣은 뒤 다시 뽑음: extract.py는 GEARART 장 수 · 단계가 늘면 쓰일 그림의 이름(WNAME)도, cards.py의 「그림은 아직 없어요」 줄은 종류마다 그림이 끝나는 착용 레벨부터.
