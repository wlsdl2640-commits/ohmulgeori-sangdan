## 새 디자인을 넣을 때 정할 것 (사용자에게 알림)
- GPT는 104장(13 × 8)을 같은 모습으로 그리기 어렵다 → 동작마다 핵심 자세 3장(준비 · 휘두름 · 마무리)을 받고, 칼 자취 · 효과로 사이를 잇는다.
- 무기 · 방패: 지금은 장비한 무기 · 방패 단계 색을 코드가 손에 그린다. GPT가 칼 · 방패를 든 채로 그리면 전투에서 장비 단계가 안 보이게 된다 → 몸만(빈손 쥔 자세) + 무기 · 방패 따로 받거나, 든 채로 받고 장비 단계는 창고 그림에서만 보이게 할지.
- 크기: 옆모습 26×34 픽셀(지금 뭉툭 13×17칸) — 몬스터 리마스터 1과 같은 굵기(논리 1px = 한 도트)로 맞추면 지금보다 두 배 촘촘. 새 그림이 오면 목업으로 크기부터.
