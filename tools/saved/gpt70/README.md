## 부탁 글 (사용자에게 준 그대로)

### 1. 첫 메시지 — 붙일 것: plains_1_screens · plains_2_layers · gpt_in_mid
```
너는 픽셀 아트 게임 그래픽 디자이너야. 내가 만드는 모바일 방치형 RPG 「미궁도시」의 첫 원정지 「평원」 그래픽을 업그레이드하려고 해.
첨부: plains_1_screens = 지금 게임 화면 / plains_2_layers = 배경 겹 다섯 장(크기 · 흐르는 빠르기) / gpt_in_mid = 이번에 업그레이드할 그림.

[게임 화면]
- 옆에서 보는 화면. 파티가 왼쪽에서 오른쪽으로 걷고, 몬스터는 오른쪽에서 나와 왼쪽을 보며 싸운다.
- 화면은 가로 240 × 세로 200 도트, 배경은 그 아래쪽 128줄. 배경은 가로 480 도트(화면 두 개 너비)짜리 겹 다섯 장이고, 걸을 때 옆으로 흐른다(먼 겹일수록 느리게).
- 무대: 파로스 왕국의 미궁도시 하르겐에서 모험가들이 처음 나가는 원정지 「평원」 — 밀밭과 농가가 있는 넓은 들판.
- 하늘 · 해 · 달 · 구름 · 밤의 어둠 · 비 · 눈, 먼 겹에 덮이는 하늘빛 안개는 게임이 시간대와 날씨에 맞춰 따로 그린다. 그러니 하늘은 그리지 말고, 밝은 한낮 색으로만 그려 줘.

[화풍]
- 16비트 시절 느낌의 픽셀 아트. 정사각형 도트가 고르고 또렷하게, 3단 명암(빛은 왼쪽 위), 진한 테두리.
- 그러데이션 · 흐림 · 안티에일리어싱 · 반투명 빛 · 사진 같은 질감은 쓰지 마. 겹 하나에 32색 안쪽.
- 지금 그림의 구성과 자리를 바탕으로 디테일 · 색 · 질감을 올려 줘. 소품을 조금 더해도 좋아(돌담 · 나무 수레 · 꽃밭 같은 것).
- 피할 것: 십자 · 더하기(+) · X 꼴 무늬(엇갈린 막대 · 격자 창살 포함), 바람개비처럼 한쪽으로 꺾인 날개, 후광, 흰 옷 · 너울, 한자처럼 보이는 무늬, 유명한 게임 · 캐릭터 · 브랜드를 닮은 것.

[출력 규칙]
- 한 번에 한 장. 그림 안에 글자 · 숫자 · 크기 표시를 넣지 마.
- 참고 판의 회색 바둑판과 원본의 마젠타는 「투명」 표시야. 바둑판은 그리지 말고, 빈 곳(하늘 자리)은 단색 마젠타(#FF00FF)로 채워 줘. 그림 안에는 마젠타를 쓰지 마.
- 가로로 긴 띠 그림(가로:세로 = 480:128). 캔버스가 더 높으면 띠를 가운데 두고 남는 위아래도 마젠타로.
- 왼쪽 끝과 오른쪽 끝이 자연스럽게 이어지게(가로로 끝없이 반복된다).

먼저 gpt_in_mid(중경 들판)를 업그레이드해 줘. 풍차는 몸통만 — 날개는 게임이 따로 돌리니 그리지 마. 들판 아래 마젠타 자리는 땅 띠가 덮는 곳이니 그대로 비워 둬.
```

### 2. 다음 메시지들 — 붙일 것: 그 겹의 gpt_in_* 하나씩
```
같은 화풍으로 gpt_in_far(먼 언덕)를 업그레이드해 줘. 언덕은 그림 맨 아래까지 꽉 채우고(앞 겹에 가려진다), 중경보다 단순하게.
```
```
같은 화풍으로 gpt_in_back(먼 산)을 업그레이드해 줘. 산은 맨 아래까지 꽉 채우고, 가장 먼 겹이니 가장 단순하게.
```
```
같은 화풍으로 gpt_in_ground(땅 띠, 가로:세로 = 480:28)를 업그레이드해 줘. 빈 곳 없이 꽉 차게 — 위는 풀, 가운데는 캐릭터가 걷는 흙길, 아래는 풀과 들꽃.
```
```
같은 화풍으로 gpt_in_fore(앞 풀, 가로:세로 = 480:28)를 업그레이드해 줘. 마젠타 바탕에 키 작은 풀포기 · 꽃 · 작은 돌만 듬성듬성(캐릭터 앞에 깔린다).
```
```
이번엔 풍차 날개만 따로 그려 줘. 정사각 그림, 마젠타 바탕, 날개 축이 그림 한가운데. 날개는 다섯 장(네 장 말고). 중경 풍차 몸통에 맞는 크기 · 색으로.
```

```
이제 평원 몬스터 여섯을 같은 화풍으로 업그레이드해 줘. plains_3_monsters가 지금 그림이고, plains_1_screens에서 모험가와 같이 선 크기를 볼 수 있어.

- 옆모습, 오른쪽을 본다(게임이 뒤집어서 왼쪽을 보게 한다).
- 몬스터 하나에 한 장. 그 장에 동작을 가로로 나란히 — 한 장에 같이 그려야 생김새가 똑같이 유지된다. 모두 같은 크기 · 같은 발 높이.
  · 서 있기 2장: 숨쉬는 모습(거의 같고 조금만 다르게)
  · 들쥐 · 들늑대: 입 벌린 물기 · 뛰어오른 덮치기
  · 뿔토끼: 고개 숙인 들이받기 · 뛰어오른 덮치기
  · 슬라임: 납작하게 눌린 모습 · 위로 길게 늘어난 모습

- 도트는 모험가처럼 굵게. 지금 칸 수(가로 × 세로)와 비슷하게: 들쥐 18×8 · 슬라임 12×9 · 뿔토끼 14×11 · 들늑대 21×12 · 고블린 14×14 · 들쥐왕 21×18.
- 몬스터 하나에 16색 안쪽, 눈은 2칸 이상으로 또렷하게, 빛은 왼쪽 위.
- 바탕은 단색 마젠타(#FF00FF). 발밑 그림자 · 땅 · 글자 · 이름 없이, 그림 안에는 마젠타를 쓰지 마.

먼저 들쥐부터 그려 줘.
```
