  노드 자리(map.js MAP_NODES · MAP_KINGS · MAP_ORGS)는 그대로 — 240×240 논리 픽셀, 마계는 y 204 아래.
  `keep_clear()` = 노드 단추 · 이름이 얹히는 자리(장식을 안 둔다).
- `map_a.py` — **A 양피지 고지도(사용자가 고름 · 게임 대륙 지도)**: 얼룩진 양피지 · 잉크 선 · 옅은 물감 · 바다 가로 빗금과 물결 선 · 잉크 나무/산/메사/비석 기호 · 붉은 점선 길 · 겹테두리와 마름모 모서리.
- `sky_a.py` — 하늘 지도(구름섬, 240×150)를 같은 결로: 양피지 + 옅은 하늘 물감 · 바닥 구름 바다 · 뜬 섬(풀 윗면 + 거꾸로 선 바위 밑동 · 빗금 · 줄무늬 · 늘어진 뿌리) ·
  구름섬(나무 · 폭포 · 구름 위 신전) · 천둥 봉우리(잿빛 바위 · 먹구름 · 번개 · 뇌신의 첨탑) · 천계의 유적 폐허(부러진 기둥 · 무너진 아치 · 성소) ·
  별의 정원(밤하늘 물감 · 별 · 별자리 점선 · 별꽃 나무 · 뜬 바위 위 별의 왕좌) · 작은 섬 둘 · 붉은 점선 하늘길 · 비행 마차 · 나는 새 · 바람 줄기 · 왼쪽 아래 나침반.
  노드 자리(map.js MAP_NODES_SKY · dun)는 그대로, 던전 그림은 던전 노드 자리에(찾으면 노드 단추가 덮는다).

- 게임에 넣기: `python3 export_mapart.py <저장소>/src/data-mapart.js [미리보기.png]` → `MAP_ART`(240×240 색 판 PNG) · `SKY_MAP_ART`(240×150 PNG) data URL.
