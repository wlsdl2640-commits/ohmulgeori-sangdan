# 빌드 66 지도 시안 (11-12 21:47 사용자 「지도도 너무 그림판 그림이야 새롭게 그려」 — 고르는 중, 게임에는 안 넣음)

- `geo66.py` — 땅 모양 하나(바다 · 프라마 섬 · 숲 · 묘지 · 산 · 화산 · 설산 · 협곡 · 사막 · 마계 경계 · 강 둘 · 길)를 두 그림이 같이 쓴다.
  노드 자리(map.js MAP_NODES · MAP_KINGS · MAP_ORGS)는 그대로 — 240×240 논리 픽셀(게임은 두 배 480×480으로 굽는다), 마계는 y 204 아래.
  `keep_clear()` = 노드 단추 · 이름이 얹히는 자리(장식을 안 둔다).
- `map_a.py` — A 양피지 고지도: 얼룩진 양피지 · 잉크 선 · 옅은 물감 · 바다 가로 빗금과 물결 선 · 잉크 나무/산/메사/비석 기호 · 붉은 점선 길 · 겹테두리와 마름모 모서리.
- `map_b.py` — B 도트 지형(16비트 RPG 필드 지도처럼): 풀 3톤 바둑 무늬 · 바닷가 모래와 깊이별 바다 · 숲 나무 도장 · 산기슭 언덕 + 산봉우리(가운데일수록 높게, 눈 덮인 꼭대기) · 설산과 전나무 ·
  사막 모래 언덕 · 선인장 · 오아시스 · 협곡 메사(평평한 꼭대기 · 붉은 벼랑) + 골짜기 강 + 바람 줄기 · 묘지 비석 · 울타리 · 안개 띠 · 세계수 · 화산 · 하르겐 성벽과 지붕 · 왕국 성 · 배 ·
  마계 경계 벼랑(붉은 금) · 늪 · 재의 땅 용암 금 · 검은 성.
- 나침반은 북쪽 화살 + 고리 + N(십자 꼴 피함), 모서리 장식은 마름모.
- `python3 map_a.py <출력.png> [배율]` · `python3 map_b.py <출력.png> [배율]` → `preview.py <출력.png> <시안 2배 png|current> [DPR]`(게임 빌드에 `__EV` 훅을 걸고 `MAP_CV`를 바꿔 지도 창을 찍는다 — 경로 D는 세션 작업 폴더 scratchpad/v70/).
- `map_drafts66.png` — 지금 지도 · A · B를 실제 지도 창(노드 · 이름 얹힘)으로.
- 고르면: 고른 쪽을 240×240 PNG로 뽑아 data URL로 넣고(`src/data-mapart.js`), map.js `mapArt()`가 그것을 두 배로 굽게(MAP_EXTRA는 그림에 들어가니 지운다). 하늘 지도(skyMapArt)도 같은 결로 새로.
