- `sim100.js` · `dummy100.js` — stat69/v99 sim99 · dummy99에 더한 것:
  - `cdT[공용, 1차, 2차, 3차, 4차]` 차수별 재사용 ×(지속 · 때린 뒤 강화도 같은 배)

- `run100.sh` · `dsweep100.sh` · `an99.py` · `band99.py` · `dan100.py` — v99와 같은 꼴(out/ · dout/, 없으면 `results100.json.gz`를 읽게 고쳐 쓴다).
