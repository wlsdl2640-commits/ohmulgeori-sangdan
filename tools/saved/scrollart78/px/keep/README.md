- books/ : 직업 스킬북 후보 전부(b_<계열>_<0~3>.png = 판의 1 ~ 4번). 고른 것: 전사 1 · 궁수 4 · 도적 1(+ 4번 열쇠) · 짐꾼 1 · 공용 1 · 마법사는 다시(고리 주문 · 룬). 나머지는 새 1차 직업 · 다른 책 디자인에 쓴다.
- quest/ : 주문서 A(말린 두루마리 + 봉인) 넷 — 임무 · 퀘스트 받을 때 쓰는 그림.
- eastern/ : 주문서 C 2 · 4번(나무 손잡이 + 술) — 특정 종족 · 동양풍.
- eastern_rates/ : C4에 확률 색(100 · 80 · 60 · 30 · 10)을 입힌 것.
- holy/ : 주문서 B 3번 — 종교 쪽.
- 강화 주문서 = B 1번(파란 리본 없이), 확률은 양피지 색 · 낡은 정도로 (../rate/).
