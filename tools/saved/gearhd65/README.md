# 큰 도트 장비 그림 시안 (빌드 65 — 화살통 · 마나소드)

사용자(11-12 15:26): 「화살통 16단계 … 이거 작업하고, 이번에 새로 들어간 장비 수준에 맞게 디자인해봐 디자인 방식배워서」 ·
「마검사 무기를 룬소드에서 마나오러, 빛등이 사출되는 광선검으로 변경한다. 이름은 마나소드」.

사용자가 준 방어구 · 신발 · 벨트 그림(ARMART, 긴 쪽 96px)과 나란히 놓이도록 코드로 그린 그림이다. **시안 — 고르기 전에는 게임에 넣지 않는다.**

- `hd2.py` — 그림판. 64칸 판에 부위(가림판 · 밝기 0 ~ 1 · 재질 색 띠 일곱 톤)를 차례로 얹는다.
  배운 방식: 굵은 검은 바깥 테(8방향) · 아래 · 오른쪽 가장자리 안쪽 한 줄 그늘 · 부위가 겹치는 곳은 그 부위의 짙은 색 테 ·
  위 · 왼쪽 가장자리 한 줄 빛 · 둥근 몸은 띠 명암 + 그늘 쪽 되비침 · 쇠는 좁고 센 빛 띠 · 가죽 얼룩 ·
  띠 아래 그림자 · 빛나는 부위는 제 빛깔 테 + 둘레 빛. 96px로 낼 때 6배로 키웠다가 줄여 살짝 부드럽게.
- `quiver_hd.py` · `quiver16.py` — 화살통(Lv1 ~ 150). `python3 quiver16.py <출력 폴더> [번호,…]`
- `msword_hd.py` · `msword16.py` — 마나소드(Lv50 ~ 200, 마검사 · 마검성). `python3 msword16.py <출력 폴더> [번호,…]`
- `quiver_drafts.png` · `msword_drafts.png` — 시안 판(왼쪽 위 작은 그림 = 게임 창고 칸 크기 40px).
- 판 글꼴: 환경 변수 `GALMURI_DIR`(Galmuri11.ttf · Galmuri11-Bold.ttf가 있는 폴더, 끝에 `/`).

마나소드: 사용자가 붙인 작은 그림 넷은 다른 게임의 그림으로 보여 꼴(작은 자루에서 넓은 마나 날이 뿜어 나옴 ·
흰 심 → 밝은 몸 → 짙은 가장자리)만 따르고 새로 그렸다. 저장소에는 넣지 않았다.
이름 · 설명은 모두 제안. 칼끝 빛 조각은 더하기 꼴이 되지 않게 점 · 비스듬한 두 칸으로.
