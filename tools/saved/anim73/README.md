# 몬스터 동작을 부드럽게 — 픽셀랩 사이 장 채우기 (11-25 밤)
대표님: 「이전에 만들었던 몬스터들의 프레임도 다 부드럽게 나올 수 있게 더 추가해 줘 — 픽셀랩에 올려서 더 추가하든, 안 되면 다시 뽑아서 행동 프레임 다시 짜」.
- 방법: 지금 게임 그림(hd70/extract_mon.py → out_mon — GPT 판에서 뽑은 장)의 **동작마다 첫 장 · 끝 장**을 픽셀랩에 올리고 `animate_image_pixminimax`로 사이를 채운다. 서 있기 · 걷기 = 16장(끝 = 첫 장, 반복), 공격 · 특수 · 쓰러짐 = 20장(끝 = 원래 끝 장).
- 시험(들늑대): 생김새 · 색이 거의 그대로. 다만 물기 중간에 픽셀랩이 섬광 · 핏방울 효과를 덧그려서 본작업 지시문에 「효과 없이」를 붙였다(효과는 게임이 그린다). 비교 `wolf_compare.png`.
- 대상: 고블린 셋을 뺀 25종 · 동작 89개(평원 6 · 원시림 7 · 깊은 숲 8 · 뿌리굴 4). 비용 동작마다 2 ~ 3생성분.
- `prep.py <업로드 주소>` → jobs_in.json(첫 장 · 끝 장 upload ref · 지시문) · `run_anim.mjs [동시 수]` → `<몬스터>/<동작>/00.png …`(00 = 입력 첫 장) · jobs_done.json · log.txt. 토큰은 ~/.claude.json의 pixellab 설정에서 읽어 프로세스 안에서만 쓴다.
- 게임에 넣는 것은 대표님이 보고 고른 뒤(export_hd70.py / mid70 쪽에서 장 수를 늘려 읽게).
