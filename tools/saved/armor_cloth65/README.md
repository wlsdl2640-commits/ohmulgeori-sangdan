# 천갑 확정 디자인 (사용자 11-12 12:07)

사용자 말: 「두번째는 천갑 상, 하의야 추가해」

- 사용자가 ChatGPT와 만들어 보낸 확정 디자인. 게임에 그대로 쓰는 그림이라 저장소에 둔다(경갑과 같은 예외).
- `천갑_상의하의_Lv1-200.png` — 「천갑 세트 (상/하)」: 왼쪽 「구조 및 특징」(천(아마포) 기반 · 가죽 보강 · 끈 · 벨트 구조) · 「기본 실루엣 예시」 · 「주요 재질」, 오른쪽 천갑 상의 21개(3줄 × 7), 아래 천갑 하의 21개(11 + 10). Lv1 · 10 · … · 200. **받은 판의 맨 위 제목 줄(세트 이름 · 방어구 유형 천갑 · 주요 직업 검객 · 레인저 · 마법사 · 제작자 이름)은 빼고 저장했다** — 사람 이름이 저장소에 들어가지 않게.
- 판의 설명 글(게임 설명으로 씀): 천갑 상의 「천을 기본으로 제작하고, 보호가 필요한 부위에 가죽을 덧댄 경량 보호구.」 · 천갑 하의 「가볍고 유연한 천을 기반으로, 무릎·허리·허벅지 등 주요 부위를 가죽으로 보강한 하의.」
- 게임: 새 「천갑」(cloth, 방어구 칸) · 「천갑 하의」(cpants, 하의 칸). 입는 직업 = 궁수 계열(사용자 11-10 구분: 천 = 궁수 · 판의 레인저) · 마법사 계열(판의 마법사). **판의 「검객」은 아직 게임에 없는 직업** — 생기면 넣는다. 가죽 갑옷보다 방어는 낮고 민첩은 높고 가볍다(기본값 — 사용자 확인 전).
- 게임에 넣는 길: `../armor_light65/export_armart.py`(`cards_dark`, `DARK['cloth' · 'cpants']`) → `src/data-armart.js`의 cloth · cpants.
