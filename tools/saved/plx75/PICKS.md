## 다시 뽑은 것 고름 (11-25 낮 둘째)
- 9층 보스 = **A안 갈대관 사마귀 03** (b9_mantis/03).
- 갈대관 늪물소 **01은 보스 말고 일반 몬스터로** 넣는다(b9_buffalo/01 — 일반 크기로 줄여 쓸 것, 층은 9층 갈대 늪으로 두고 c7 칸 배치는 다음 회의 때).
- 13층 독볏 도롱뇽 = **00** (salamander2/00).
- 14층 진흙등 악어 = **01** (caiman2/01).
- 떠돌섬 포식자 오두막: 덧그린 21장은 「어색하다」 → 쓰지 않음. 오두막 + 늪 판자길을 처음부터 프롬프트에 넣어 다시(b14_island2/h0~h5).
