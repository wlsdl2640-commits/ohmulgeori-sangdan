판타지상단키우기 {VER} (빌드 {N}) — PC 판 (윈도우 10 · 11, 64비트)

1. 실행
   - 압축을 아무 폴더에나 푼 뒤 「판타지상단키우기.exe」를 두 번 누릅니다. 설치는 필요 없습니다.
     (압축 프로그램 안에서 바로 누르지 말고, 꼭 먼저 풀어 주세요.)
   - 처음 실행할 때 「Windows의 PC 보호」 창이 뜨면 「추가 정보」 → 「실행」을 누릅니다.
     (개인이 만든 서명 없는 프로그램이라 뜨는 알림입니다.)
   - 바탕 화면에 두려면 exe를 마우스 오른쪽 단추로 눌러 「바로 가기 만들기」 → 바로 가기를 바탕 화면으로 옮깁니다.

2. 화면 · 단추
   - 게임 화면은 폰 판과 같은 세로 화면입니다. 창 크기는 마음대로 바꿀 수 있고, 다음에 켤 때 그대로 열립니다.
   - Ctrl + 마우스 휠 또는 Ctrl + / Ctrl - : 화면 크게 · 작게   ·   Ctrl + 0 : 원래 크기
   - F11 : 전체 화면 켜기 · 끄기   ·   Esc : 전체 화면 끄기

3. 저장
   - 진행 상황은 이 PC의 %APPDATA%\ohmulgeori-sangdan-pc 폴더에 저장됩니다.
   - 새 판이 나오면 새 폴더에 풀어서 실행해도 저장이 그대로 이어집니다. 옛 폴더는 지워도 됩니다.
   - 폰 · 웹 판과 저장을 옮기려면: 상단 → 설정 → 「저장 코드 만들기」로 코드를 복사해,
     다른 쪽 「저장 코드로 불러오기」(첫 화면에서는 「저장 코드로 이어하기」)에 붙여 넣습니다.

4. 지우기
   - 압축을 푼 폴더를 지우면 됩니다. 저장까지 지우려면 위 저장 폴더도 지웁니다.
